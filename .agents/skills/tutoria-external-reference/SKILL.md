# Tutoria external reference workflow

Default:
`STUDY -> ABSTRACT -> TUTORIA-NATIVE DECISION`.

Capture the external problem solved, workflow, states, UX/architecture pattern, tradeoffs, and what Tutoria already has. Then classify each pattern `ADOPT`, `SIMPLIFY`, `CHANGE`, or `REJECT`.

Direct incorporation/adaptation is optional and requires exact-material license/provenance approval. In `STUDY_ONLY`, do not port restricted implementation structure or code; use safe public behavior/docs to produce a Tutoria-native specification.
